Voice settings
Help and starting values

Keep a working setup and change one control at a time. These are starting points, not universal limits. Save changes and start a new voice session to test them; XVF gain applies immediately.

Model and voice
Keep the model and voice you like unless you are testing quality or latency. Changing speaker voice or volume can change acoustic leakage, so retest barge-in afterward.
Reasoning effort
low is a responsive starting point; try medium only when complex questions or tool use need more reasoning.
Noise reduction
far_field suits the ReSpeaker room microphones; near_field is for close-talking mics. Use off mainly to diagnose audio.
VAD mode
server_vad uses the threshold and silence controls below. semantic_vad decides when a thought is complete and instead uses eagerness.
Semantic eagerness
auto is the default; low waits longer for you to finish. Ignored in Server VAD mode.
Server VAD threshold
OpenAI's scale is 0–1, with 0.5 as its default. Higher values reject more faint sound but can miss soft speech. This is separate from the gateway RMS gates.
Server VAD silence
500 ms is the OpenAI default. Shorter responds sooner; longer gives you more time to pause mid-sentence. Ignored in Semantic VAD mode.
Idle timeout
600–900 seconds allows a 10–15 minute hands-free pause; 0 disables the idle timeout, but the session still has a hard limit. This only counts while listening, not while speaking.
Project announcement
Enable for audible confirmation of the active project; disable for a quiet start.
Spoken barge-in
Enable to interrupt assistant speech with your voice. Disable when you want playback protected from interruptions.
Barge-in minimum RMS
Local 400 ms PCM level during playback, not OpenAI VAD. 3000 worked in one test on this setup; raise it if speaker echo interrupts, lower it if you must speak too loudly. 0 disables this local gate, not VAD. The first second of playback is guarded separately.
XVF channel-0 gain
25 is this setup's fixed-gain baseline; 0 restores adaptive AGC. Only applies to connected XVF-compatible devices.
Listening minimum RMS
800 is this setup's baseline while the assistant is not speaking. Raise it if small noises start turns; lower it if your quiet voice is missed. 0 disables this local gate.
Trace and recordings
Leave off for normal use. OpenAI trace adds event logs; diagnostic audio saves raw microphone and output recordings, which may contain private speech and use storage.

Neither RMS gate measures AEC quality by itself. A quiet speaker-only run at 3000 is encouraging, but AEC, the gateway gate, and OpenAI VAD all contribute. See the OpenAI VAD guide for the cloud settings.
