## 1. System Architecture
```
[ReSpeaker Lite Mic Array] ---> (Hardware AEC / Noise Filters via XMOS XU316)
                                        | (Low-Latency 48kHz I2S Bus)
                                        v
[XIAO ESP32-S3 Satellite] <---> (Custom Real-Time Duplex WebSocket Client)
                                        | (Local Network WiFi / Secure Socket)
                                        v
[Home Assistant Proxy Backend] <---> [OpenWebUI Pipelines Server] <---> [Hermes Agent Model]
```

---

## 2. Mandatory Pre-Flight Hardware Checklist
* [ ] **Flash XMOS Chip to 48kHz I2S Mode:** Connect your PC directly to the **Main Board USB port** (not the ESP32 port). Flash the XMOS XU316 chip with the official **Seeed Studio 48kHz I2S Firmware v1.1.0+** [Seeed Wiki](https://wiki.seeedstudio.com/xiao_respeaker/). The base 16kHz USB-OTG profile will fail to interface with high-fidelity real-time streaming wrappers.
* [ ] **Hardware Button Jumpering:** Solder the `USR` pad to pin `D2` and the `MUTE` pad to pin `D3` on the rear of the board if you want physical mute/trigger buttons to fire state flags inside the firmware [FormatBCE Repo](https://github.com/formatBCE/Respeaker-Lite-ESPHome-integration).
* [ ] **Power Allocation:** Ensure the board is supplied via a stable 5V/2A+ source. ESP32-S3 bursts during simultaneous audio encode/decode + high-throughput WiFi TX can trip brownout resets on generic PC USB 2.0 ports.

### Phase 2: Hardware Core Implementation (Firmware Stub)
```cpp
#include <Arduino.h>
#include <WiFi.h>
#include <WebSocketsClient.h>
#include <driver/i2s.h>

// Strict Seeed XIAO ESP32S3 to XMOS XU316 I2S Pin Mapping
#define I2S_MCLK      GPIO_NUM_7
#define I2S_BCK       GPIO_NUM_8   // D8 / SCLK
#define I2S_WS        GPIO_NUM_9   // D9 / LRCK
#define I2S_DIN       GPIO_NUM_10  // D10 / SDIN
#define I2S_DOUT      GPIO_NUM_4   // D4 / SDOUT

// Audio Configurations matching the 48kHz XMOS Core
#define SAMPLE_RATE   48000
#define BUFFER_SIZE   1024

WebSocketsClient webSocket;
void handleWebSocketEvent(WSType_t type, uint8_t * payload, size_t length);

void setup() {
    Serial.begin(115200);
    
    // I2S Driver Setup for Full-Duplex Transceiver Mode
    i2s_config_t i2s_config = {
        .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_TX | I2S_MODE_RX),
        .sample_rate = SAMPLE_RATE,
        .bits_per_sample = I2S_BITS_PER_SAMPLE_16BIT,
        .channel_format = I2S_CHANNEL_FMT_RIGHT_LEFT,
        .communication_format = I2S_COMM_FORMAT_STAND_I2S,
        .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
        .dma_buf_count = 8,
        .dma_buf_len = BUFFER_SIZE,
        .use_apll = true
    };
    
    i2s_pin_config_t pin_config = {
        .bck_io_num = I2S_BCK,
        .ws_io_num = I2S_WS,
        .data_out_num = I2S_DOUT,
        .data_in_num = I2S_DIN
    };
    
    i2s_driver_install(I2S_NUM_0, &i2s_config, 0, NULL);
    i2s_set_pin(I2S_NUM_0, &pin_config);
}

void loop() {
    webSocket.loop();
    
    uint8_t rx_buffer[BUFFER_SIZE];
    size_t bytes_read = 0;
    
    // Non-blocking stream read from the ReSpeaker XMOS AEC engine
    if (i2s_read(I2S_NUM_0, &rx_buffer, BUFFER_SIZE, &bytes_read, portMAX_DELAY) == ESP_OK) {
        if (bytes_read > 0 && webSocket.isConnected()) {
            webSocket.sendBIN(rx_buffer, bytes_read);
        }
    }
}
```
